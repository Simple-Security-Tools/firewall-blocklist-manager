to stay aligned with microsoft conditional access policy named locations:

1) DONE — blocks wider than /16 refused, /23-/16 require typed confirmation
2) 2000 CIDRs per named location - when exporting or syncing block lists, warn if the list will require more than 1 named location
3) Note that you cannot create a named location with no entries. You always need 1 entry to initialize it.

4) Allow carve-out while DENY_ONLY is set. Removing a narrower range from inside
   a covering block currently needs the allow path, which DENY_ONLY disables.
   The carve-out should be permitted, but the resulting entries must stay
   internal: no ALLOW list should be written to FILE_OUTPUT_ALLOW while
   DENY_ONLY is TRUE.

5) Sync does nothing when every rule has expired. The list is empty, so it bails
   before calling Graph and Entra keeps enforcing the last list it was given.
   Entra rejects an empty Named Location, so it cannot simply push nothing.
   Decide what should happen: warn harder, or leave a single placeholder CIDR.
